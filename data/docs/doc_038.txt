Document ID: PAY-038 | Domain: Payment Gateway & Transaction Processing
======================================================================

Billing and invoicing: subscription management, proration, tax calculation, and invoice generation.

Multi-currency: store amount in minor units (cents). Display in major units. Use ISO 4217 codes.

Payment API integration guidelines: REST endpoints, authentication, webhook callbacks, and error code handling.

Additional context:
- Payment gateway configuration requires secure token handling and PCI-DSS compliance.
- EU region transactions mandate PSD2 and Strong Customer Authentication (SCA).
- Error code 5003 indicates gateway connection timeout; check network and gateway health.
- For INR/USD discrepancies verify FX rate source and conversion timestamp.

Troubleshooting steps:
1. Verify gateway connectivity and SSL certificate validity
2. Check transaction logs for specific error codes
3. Validate amount and currency for multi-currency transactions
